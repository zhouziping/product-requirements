## 维护说明

- 从[增量 Story 模板](../../templates/story.md)复制到本目录，每项增量单独成文，使用稳定编号或简短名称作为文件名。
- 引用[功能规格](../features/README.md)的具体基线版本与条目，说明新增、修改或移除，不重复整份规格。无既有基线时注明事实及依据。
- 增量范围、优先级、兼容影响及业务确认状态须有依据，缺失信息保持待确认，不以建议代替业务决定。
- 关联[验收场景](../acceptance/README.md)，并在规格实际更新后记录对应版本，保留增量与整体规则的追溯关系。
- 新增或修改后同步[需求概述索引](../requirements-overview.md)，检查模板复制后的相对链接。

遵循[维护约定](../../AGENTS.md)。Story 确认与文档 PR、实现、验证和上线状态分开记录。
