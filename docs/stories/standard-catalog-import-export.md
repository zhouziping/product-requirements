## 2. 来源、问题与目标

依据为目标规格中的 SRC-SC-01（需求方授权公开的脱敏整理 v0.1）；原始来源待提供可公开版本，不公开内部标识或聊天。以下「原规则」是需求方说明的现状，并非经产品验证的基线。

使用范围为维修手册、用户手册、拆解手册的标准目录。目标是通过异步导入查看任务结果、避免导入时翻译数据同步回流、统一翻译维护路径，并使导出翻译文件可供业务数据翻译管理直接导入；不设定未提供的性能指标。

## 3. 增量范围

| 增量编号 | 类型 | 需求方说明的原规则 | 目标规格条目与变化 |
| --- | --- | --- | --- |
| SC-D01 | 修改 | 导入同步执行，接口返回结果 | SC-R01：改为异步任务，立即返回任务 ID，通过任务页面查看进度与结果 |
| SC-D02 | 移除 | 有导入翻译入口；导入过程同步写翻译数据 | SC-R02：取消前端入口，并移除导入过程同步写翻译逻辑 |
| SC-D03 | 维护路径说明 | 未提供其他现状，不推断为新增功能 | SC-R03：批量经翻译管理导入，少量经翻译管理或标准目录单条编辑 |
| SC-D04 | 修改 | 导出翻译取 name_en | SC-R04：选择「英文」时改取海外英文翻译值 |
| SC-D05 | 修改与新增 | 原文件表头见 SC-R05 | SC-R05：两列改名，新增大写语言编码列，其余字段不变；目标为直接导入翻译管理 |
| SC-D06 | 不变边界 | 导出同步下载；未提供检入/检出完整规则 | SC-R06：普通导出保持同步下载，检入/检出不变 |

精确取值表达式、字段对照与边界以目标规格为唯一维护位置，本 Story 不重复维护。导出翻译保持同步下载与交互不变，见 SC-R04。

本次不包含产品实现、排期决策、任务页面重设计或后端接口删除。异常、空翻译回退、其他语言及普通导出的字段适用范围不自行确定。
