## 维护说明

- 从[验收场景模板](../../templates/acceptance-scenario.md)复制到本目录，每个场景单独成文，使用稳定编号或简短名称作为文件名。
- 引用[功能规格](../features/README.md)条目、版本及适用的 [Story](../stories/README.md)，描述前置条件、操作和可观察的预期结果。
- 未确认的阈值、异常行为与边界条件保留待确认，不按猜测补全。
- 场景描述预期，不记录实际执行通过结论；实际结果及证据另建[验证记录](../verification/README.md)，并关联执行时的场景版本。
- 新增或修改后同步[需求概述索引](../requirements-overview.md)，检查模板复制后的相对链接。

遵循[维护约定](../../AGENTS.md)。场景确认、文档合并和验证通过是不同事项。
