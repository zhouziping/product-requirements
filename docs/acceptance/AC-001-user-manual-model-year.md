## 2. 来源与适用范围

依据 ST-001 的 SRC-001 脱敏摘要：调整校验范围，不应同时取消用户手册适用的款型校验。来源待提供可公开版本。仅描述海外 TIS 发布中本次涉及的 `model_year` 校验，不代表所有用户手册发布均无条件必填。
