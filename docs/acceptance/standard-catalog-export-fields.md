| 要素 | 内容 |
| --- | --- |
| Given | 已提供可导出翻译的脱敏条目与语言，并具备业务数据翻译管理导入条件；当前导入模板、完整校验规则和被测版本待提供 |

| 判定依据 | SC-R05；须同时检查字段与真实导入兼容，不能以表头检查替代兼容性验证 |
| 所需证据 | 脱敏导出文件、对应导入模板版本及导入结果；不得伪造成功结果 |
