## 场景描述

| 要素 | 内容 |
| --- | --- |
| Given | 具备标准目录和业务数据翻译管理相关操作条件；使用脱敏的可导入数据与可编辑条目，具体账号权限、模板和被测版本待提供 |
| When | 查看标准目录操作入口并进行普通导入；另经业务数据翻译管理批量导入翻译，以及分别经业务数据翻译管理、标准目录单条编辑翻译 |
| Then | 标准目录不显示「导入翻译」按钮；普通导入不再同步写翻译数据；批量翻译可经翻译管理导入，少量修改可经上述单条编辑路径完成 |
| 判定依据 | SC-R02、SC-R03；入口检查不能替代对导入同步写翻译已移除的核验 |
| 所需证据 | 入口状态、导入流程写入行为及替代维护路径的可核实记录，不包含敏感数据 |
