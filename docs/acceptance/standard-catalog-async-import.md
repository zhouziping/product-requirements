## 场景描述

| 要素 | 内容 |
| --- | --- |
| Given | 有可使用导入入口及任务页面的测试账号，以及可正常解析、校验并落库的脱敏 Excel；具体权限、文件模板和被测版本待提供 |
| When | 在标准目录点击「导入」并上传 Excel |
| Then | 生成导入导出任务记录，立即返回任务 ID；接口不等待后台解析、校验、落库完成；后台按顺序处理并写入结果；用户可在「导入导出任务」页面查看进度和结果 |
| 判定依据 | SC-R01；立即返回表示不等待后台处理完成，不自行设定毫秒阈值 |
| 所需证据 | 提交响应、任务记录及后台处理时序的可核实证据；证据中不得含敏感数据 |
