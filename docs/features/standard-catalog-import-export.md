## 3. 范围与目标

- 适用范围：维修手册、用户手册、拆解手册的标准目录。
- 目标：将导入转为后台任务；取消标准目录的导入翻译入口和导入过程同步写翻译数据；调整导出翻译的数据口径与文件字段，使导出文件可直接用于业务数据翻译管理导入。
- 翻译维护替代路径：批量多语种维护使用业务数据翻译管理的导入；少量修改使用业务数据翻译管理或标准目录中的单条手工编辑。
- 保持不变：普通导出仍同步下载；导出翻译仍同步下载、交互不变；检入与检出不变。不据此推断这些操作的其他规则。
- 不包含：产品代码实现、部署、任务页面重设计、未给出的其他语言取值规则，以及导入翻译后端接口的删除或停用决定。
- 目标用户角色、权限、优先级、量化指标、排期：待确认。

## 4. 功能规则

### SC-R01：导入异步化

用户点击「导入」并上传 Excel 后，系统生成导入导出任务记录，立即返回任务 ID，不等待解析、校验、落库完成。

后台依次解析 Excel、校验、落库并写入任务结果；用户在「导入导出任务」页面查看进度和结果。这里只明确处理顺序与结果查看入口，不预设任务状态枚举、进度计算方式或完成时限。

### SC-R02：取消导入翻译入口及导入同步写翻译

标准目录前端隐藏或移除「导入翻译」按钮；同时移除「导入」过程中同步写翻译数据的逻辑，避免翻译管理同步回流造成的资源占用。后者属于普通导入流程，不得仅隐藏按钮而保留该写入逻辑。

此规则不等于停用所有翻译同步链路，也不等于授权删除导入翻译后端接口；其他同步机制与历史数据处理方式待确认。

### SC-R03：翻译维护替代路径

| 场景 | 维护路径 |
| --- | --- |
| 批量维护多语种翻译 | 业务数据翻译管理 → 导入 |
| 少量修改 | 业务数据翻译管理或标准目录 → 手工编辑单条 |

不新增维护入口，不自行设定权限或覆盖规则。

### SC-R04：导出翻译的英文取值

「导出翻译」选择语言为「英文」时，取 `t_source_standard_content_item.name_translate['$.en']`，该值按需求口径为海外英文，不再取 `name_en`。导出翻译仍同步下载，交互不变。

需求标题涉及「英文」与「英文（海外）」，但明确给出的选择条件只有「英文」。独立的「英文（海外）」选项是否存在、如何取值，以及翻译为空时是否回退，均待确认，不自行扩展本条。

### SC-R05：导出翻译文件字段与导入兼容

以下为「导出翻译」的字段对照；普通「导出」是否也调整字段，见 Q-SC-03，不在缺少依据时扩大范围。

| 序号 | 改造前字段名 | 目标字段名 | 变化与规则 |
| --- | --- | --- | --- |
| 1 | 目录编码 | 目录编码 | 不变 |
| 2 | 节点编码 | 节点编码 | 不变 |
| 3 | 目录中文名称 | 中文描述 | 改名 |
| 4 | 层级 | 层级 | 不变 |
| 5 | 无 | 语言编码 | 新增；值为大写，例如 EN、AR、TH |
| 6 | 目录语种名称 | 翻译描述 | 改名 |

目标为导出文件可在「业务数据翻译管理」直接导入。导入模板、列顺序约束、编码全集及完整校验规则未提供，不能仅凭表头一致宣称兼容性已通过验证。

### SC-R06：不变操作边界

普通「导出」保持同步下载，「检入 / 检出」保持不变；既有行为的完整定义与实现未核验，不额外推断文件结构、权限或锁定规则。
