# 功能规格目录

当前条目：[FS-SC-001 标准目录导入导出与翻译维护](standard-catalog-import-export.md)，v0.1，业务确认待确认，描述目标规则而非实现现状。

- 从[功能规格模板](../../templates/feature-spec.md)复制到本目录，使用稳定编号或简短名称作为文件名，每项功能单独成文。
- 记录整体规则、目标、范围、边界及其可公开依据，明确区分已确认规则、建议和待确认问题。
- 增量变化由 [Story](../stories/README.md) 记录；更新规格时保留版本、依据与关联 Story，未确认的变化不能静默成为已确认规则。
- 在正文关联[验收场景](../acceptance/README.md)及适用条目；实际结果由[验证记录](../verification/README.md)承载。
- 新增或修改后同步[需求概述索引](../requirements-overview.md)，检查模板复制后的相对链接。

遵循[维护约定](../../AGENTS.md)。模板和文档合并不代表业务批准、功能实现或上线。
