- 从[验证记录模板](../../templates/verification-record.md)复制到本目录，使用稳定编号或简短名称作为文件名；未执行时如实注明，不填入虚构结果。
- 引用[验收场景](../acceptance/README.md)的执行时版本，记录被验证对象版本、实际环境、时间及时区、操作、结果和可公开证据。
- 结论仅覆盖记录中的版本、环境和场景；证据缺失、执行受阻或未覆盖条件须如实说明，不从文档或 PR 状态推断通过。
- 复验另建记录并关联原记录；后续对象或场景更新不能覆盖历史结果，更正录入错误时记录依据。
- 新增或修改后同步[需求概述索引](../requirements-overview.md)和关联场景中的记录链接，检查模板复制后的相对链接。

遵循[维护约定](../../AGENTS.md)。只记录获授权公开的信息，不上传敏感环境数据或私密证据。
